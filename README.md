# SIKERMAPNP  
*Aplikasi Web Kerjasama Kampus – Politeknik Negeri Padang*

## 📝 Tentang  
SIKERMAPNP adalah aplikasi web yang dikembangkan untuk memfasilitasi pengelolaan kerjasama kampus di Politeknik Negeri Padang (PNP). Aplikasi ini memungkinkan pihak kampus untuk mendokumentasikan, mengelola, dan memantau aktivitas kerjasama dengan mitra (industri, institusi lain, SMK, dll).

## 🎯 Fitur Utama  
- Manajemen Mitra Kerjasama (Tambah/Edit/Hapus mitra)  
- Pencatatan Jenis Kerjasama (MoU, MoA, Perjanjian, Program Kerjasama)  
- Status Kerjasama (aktif, selesai, diperpanjang)  
- Dashboard ringkasan kerjasama kampus  
- Cetak/Laporan data kerjasama (opsional)  
- Autentikasi pengguna (admin kampus)  

## 🛠️ Teknologi  
- Bahasa pemrograman: PHP  
- Frontend: HTML/CSS/Javascript
